## Design Context

### Users

Visitors evaluating the S&P 500 MCP server in their browser. They ask company research questions and inspect actual tool calls, reasoning summaries, and interactive MCP Apps.

### Brand Personality

Precise, calm, transparent. Match the existing website, as requested by the creator.

### Aesthetic Direction

English interface, existing blue and navy brand, existing Geist typography and shadcn primitives. A focused research workspace with conversation and a results inspector. Keep compact controls, clear labels, and generous reading space.

### Design Principles

- Show actual execution events and provenance.
- Make the first useful question easy to ask.
- Give interactive results room to work on desktop and mobile.
- Preserve the existing site's visual identity.
